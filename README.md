# Aplicación de Lugares Turísticos del Ecuador

## Descripción

Esta aplicación móvil desarrollada en Flutter presenta una selección de 10 lugares turísticos representativos del Ecuador. Cada destino incluye una imagen, una descripción informativa y un enlace que permite abrir su ubicación en Google Maps.

Además, la aplicación permite marcar lugares turísticos como favoritos para acceder a ellos de forma más rápida.

## Características

* Visualización de 10 lugares turísticos del Ecuador.
* Imagen representativa de cada destino.
* Descripción informativa de cada lugar.
* Acceso directo a la ubicación mediante Google Maps.
* Sistema de favoritos para guardar lugares de interés.
* Interfaz desarrollada con Flutter utilizando widgets personalizados.

## Tecnologías Utilizadas

* Flutter
* Dart
* Google Maps (mediante enlaces externos)
* Package: url_launcher

## Instalación

1. Clonar el repositorio:

```bash

```

2. Ingresar al proyecto:

```bash

```

3. Instalar dependencias:

```bash

```

4. Ejecutar la aplicación:

